### 👨‍💻 About Me

I am a **Mechanical Engineer turned AI Engineer** with a strong foundation in mathematical modeling and optimization, specializing in **production-ready LLM Agents, RAG pipelines, and high-performance inference optimization**.

- 🤖 **Agentic AI & RAG:** Building stateful, tool-using LLM agents with **LangGraph**, **MCP (Model Context Protocol)**, **pgvector**, and **Human-in-the-Loop** workflows with strict security, evaluation, and structured outputs.
- ⚡ **Production Inference & Edge AI:** Re-engineered a Python research pipeline into **C++ (ONNX Runtime / OpenCV DNN)** achieving a **2.3x speedup**, and cut VRAM usage by **82%** (`6.4GB → 1.1GB`) via **Int8 Quantization** and Small Language Models (`Qwen2.5-Coder`).
- 🚀 **Open-Source & Independent Projects:**
  - **Store Support Agent:** Persian RAG & MCP support agent with JWT-enforced identity, atomic ticket approvals, and automated evaluation suites.
  - **Store Data Assistant:** Natural-language-to-SQL analytics agent powered by MCP, LangChain, and multi-layer read-only SQL guardrails.
  - **Local Video RAG:** Privacy-first offline video search engine built with a hybrid **C++/Python** architecture and Int8-quantized CLIP (~4x memory reduction on CPU).
- 🎓 **Teaching:** Machine Learning Instructor at **Howsam Academy**, designing hands-on exercises and real-world ML projects.
